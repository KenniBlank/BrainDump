# Gravitas (Gravity Simulation)

> This will (probably) be restricted to newtonian physics

Tech Stack:
- Language: C++ (The code is however written in C manner (No classes, no inheritance, unless needed overloading of function and operators avoided), I just needed the STL of Cpp so that I wouldn't need to rewrite vectors and all data structures)
- Graphics Library: SDL3 (Not using GPU rendering API yet, rather only default rendering used, which kinda uses GPU)
